# Skeleton Generator — Figma Plugin

Конвертирует выделенный Frame/Instance/Group в Skeleton Loading State по принципу **Ghost Frames**: плагин работает с любым экраном, опираясь только на типы узлов Figma и геометрию. Структура сохраняется 1:1, контент заменяется на skeleton-плейсхолдеры. **Без зависимостей от компонентов и переменных.**

## Установка в Figma

1. Открой **Figma Desktop** (development-плагины недоступны в браузере)
2. **Menu → Plugins → Development → Import plugin from manifest...**
3. Укажи `manifest.json` из этой папки
4. **Plugins → Development → Skeleton Generator**

## Требования

**Никаких требований.** Плагин работает с любым фреймом в Figma. Компоненты и переменные не требуются.

## Семантические роли

| Роль | Цвет | Что попадает |
|---|---|---|
| **Surface** | `#1F1F1F` | Крупные объекты: карточки, кнопки, инпуты, контейнеры с фоном |
| **Content** | `#292929` | Внутренние элементы: текст, иконки, аватары, мелкие детали |
| **Stroke** | `#333333` (1px) | Обводки инпутов и границы контейнеров (если были у исходника) |

Цвета зашиты в коде через `hex()`-хелпер — никаких переменных или токенов.

## Классификация — строго по `node.type` + геометрии (без `node.name`)

| Тип узла | Условие | Kind | Роль |
|---|---|---|---|
| `TEXT` | — | `text` | Content (см. типы текста ниже) |
| `VECTOR`, `STAR`, `LINE` | — | `icon` | Content, круглый radius |
| `ELLIPSE` | max(w,h) ≥ 24 | `avatar` | Content, круг |
| `ELLIPSE` | max(w,h) < 24 | `icon` | Content, круг |
| узел с детьми | — | `container` | Surface если был фон, иначе прозрачный + рекурсия |
| лист | w ≥ 80 или h ≥ 40 | `surface` | Surface (кнопка/инпут/карточка) |
| лист | мельче | `detail` | Content (чип/разделитель/точка) |

Контейнер красится Surface **только если у исходника был видимый фон** — чисто layout-обёртки остаются прозрачными, чтобы не залить экран серым.

## Типы текста

Определяются по числу строк (`height / lineHeight`) и размеру шрифта:

| Тип | Условие | Рендер |
|---|---|---|
| **Large** | 1 строка, font ≥ 20px | одна полоса (заголовки, акцентный текст) |
| **Small** | 1 строка, font < 20px | одна полоса (body, лейблы, кнопки, подписи) |
| **Paragraph-2L** | 2 строки | 2 полосы, последняя 60% ширины |
| **Paragraph-3L** | 3+ строки | 3 полосы, последняя 60% ширины |

## Координаты результата

```
newFrame.x = sourceFrame.x + sourceFrame.width + 80
newFrame.y = sourceFrame.y
```

Один новый узел создаётся рядом с исходным — не набор фигур по странице.

## Пересборка после правок

```bash
npm install
npm run build
```

Создаёт/обновляет `code.js` — именно его подключает `manifest.json`.
